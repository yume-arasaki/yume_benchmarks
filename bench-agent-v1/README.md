# BENCH-agent v1 — receipts

Everything the Agent Fidelity Test used, so the run can be checked or repeated.

- `prompts/` — the six fixture prompts plus the two three.js scenes, as sent
- `results/fixtures.json` — every check, both sides, two runs, with the ORBIT gate failure recorded
- `results/visual.json` — skyscraper and siege: runtime errors, paint, size
- `results/gauntlet.json` — the myllmbox pastures/fish verdicts
- `results/myllmbox.json` — the prior myllmbox entry and its site scores
- `artifacts/local/`, `artifacts/cloud/` — the generated HTML, unedited, including the broken ones

Scores: local 47/51, cloud 48/51. The cloud side was authored, not served; no endpoint was called.
