Create a single self-contained HTML file using only HTML, CSS and JavaScript. No build tools, no external assets, nothing fetched.

THE PIECE: a one-shot browser tool that looks like a screen recording of a finished pathfinding sandbox: a 40 by 40 grid of weighted terrain, start and goal markers, the explored set shaded as it grows, and the final path drawn over it in a bright line with its cost. Clicking sets the start, shift-clicking sets the goal, and a button regenerates the terrain from the seed. A header is always visible: `GRID · 40×40 · COST 27 · NODES 412 · SELFTEST 9/9`.

THE SPEC: A* on a 4-connected grid. Each cell holds an integer cost from 1 to 9 (cost to enter), or 0 for a wall; moving to a neighbouring cell adds that cell's cost. The heuristic must be admissible for this cost model. Searching must run incrementally (a few hundred node expansions per frame) so the explored set animates, and the tool must show the cost and the frontier/visited counts while it runs. An unreachable goal ends with `ok:false`.

THE API (exact, headless-testable): `window.API.path(grid, start, goal) -> {ok, cost, path}` where grid is a 2-D array of ints, start and goal are `[row, col]`, and path is an array of `[row, col]` from start to goal inclusive. `{ok:false}` when there is no path. Plain JSON in and out; the API must not touch the DOM and must work before any click.

SELF-TEST: implement `window.__selftest() -> {passed, total, failures: []}`, run it on load, show the counts in the header. Cover: three hand-checkable maps whose optimal costs are 4, 7 and 12; a map whose goal is walled off returns `ok:false`; every step in the path is 4-connected and never enters a wall; the returned cost equals the sum of the costs of the entered cells; the path starts at start and ends at goal; determinism (same map twice, same cost). Tests are run externally with other maps too.

CONSTRAINTS: deterministic — `const SEED` drives every random choice through a seeded PRNG, no Math.random. Clamp delta time to 1/30. Resize handler. Runs forever on requestAnimationFrame. CODE HYGIENE: declare every table and constant at the top; no undefined vars, no TODO, no truncated functions; no console errors. Output one complete, working HTML file. Do not wrap the file in markdown. Start with <!DOCTYPE html>.
