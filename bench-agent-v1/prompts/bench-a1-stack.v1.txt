Create a single self-contained HTML file using only HTML, CSS and JavaScript. No build tools, no external assets, nothing fetched.

THE PIECE: a one-shot browser tool that looks like a screen recording of a finished assembler-and-VM playground: a monospace assembly editor on the left with RUN, STEP and RESET, and on the right the registers, the stack, a page of memory and an output log. A header is always visible: `STACK-VM · SEED 7 · SELFTEST 12/12`.

THE SPEC: a virtual machine with exactly these opcodes — PUSH n, POP, DUP, ADD, SUB, MUL, LOAD a, STORE a, JNZ label, OUT, HALT — and 256 cells of integer memory. Assembly is one instruction per line, `;` starts a comment, labels are `name:` at line start, numbers are decimal integers, arithmetic wraps at 2^31. LOAD pushes memory[a], STORE pops into memory[a], JNZ pops the top and jumps to a label (resolved before running) when it is non-zero. OUT prints the top of the stack and pops it. Execution stops at HALT, at an error, or after 10000 instructions (status `halted-cap`). STEP executes one instruction and shows the machine after it; the editor highlights the current line.

THE API (exact, headless-testable): `window.API.run(src) -> {status, output, regs, steps}` where status is `ok`, `error` or `halted-cap`; output is an array of numbers; regs is `{pc, sp}`; steps is an integer. Also `window.API.assemble(src) -> {ok, instructions}` or `{ok:false, error}`. Plain JSON in and out; the API must not touch the DOM and must work before any click.

SELF-TEST: implement `window.__selftest() -> {passed, total, failures: []}`, run it on load, show the counts in the header panel. Cover: factorial 5 ends with output 120; fibonacci 10 ends with 55; a loop that sums 1..10 ends with 55; a pop on an empty stack returns status `error` and does not throw; an infinite loop returns `halted-cap` with exactly 10000 steps. The tests are run externally with different programs too, so hardcoding outputs is pointless.

CONSTRAINTS: deterministic — `const SEED` drives every random choice through a seeded PRNG, no Math.random. Clamp delta time to 1/30. Resize handler. Runs forever on requestAnimationFrame. CODE HYGIENE: declare every table and constant at the top; no undefined vars, no TODO, no truncated functions; no console errors. Output one complete, working HTML file. Do not wrap the file in markdown. Start with <!DOCTYPE html>.
