Create a single self-contained HTML file using only HTML, CSS and JavaScript. No build tools, no external assets, nothing fetched.

THE PIECE: a one-shot browser tool that looks like a screen recording of a finished project planner: a task table with durations and dependencies, a Gantt chart drawn from it, a workers selector (1 to 3), and the critical path highlighted in a second colour. A header is always visible: `PLANNER · 14 TASKS · MAKESPAN 8d · SELFTEST 10/10`.

THE SPEC: tasks are `{id, dur, deps:[ids]}`. Compute earliest start and finish by dependency, with a resource constraint: at most `workers` tasks may run at once, and a task may only start when a worker is free and all its dependencies have finished. The makespan is the maximum finish. The critical path is the chain of tasks whose zero-slack scheduling determines the makespan; mark it in the table and the Gantt. A dependency cycle must be reported as an error, never looped through. Editing a duration or adding a dependency recomputes everything immediately.

THE API (exact, headless-testable): `window.API.schedule(tasks, workers) -> {ok, makespan, start, finish, critical}` where start and finish are objects keyed by task id, and critical is an ordered array of ids. A cycle or a missing dependency returns `{ok:false, error}`. Plain JSON in and out; the API must not touch the DOM and must work before any click.

SELF-TEST: implement `window.__selftest() -> {passed, total, failures: []}`, run it on load, show the counts in the header. Cover: A(2) → B(3), A → C(4), B,C → D(1) gives makespan 7 and critical path A,C,D; every task starts at or after all its dependencies finish; no more than `workers` tasks overlap in time; with workers 1 no two tasks overlap; with workers 3 the makespan equals the dependency critical path; a cycle returns `ok:false`. Tests are run externally with other DAGs too.

CONSTRAINTS: deterministic — `const SEED` drives every random choice through a seeded PRNG, no Math.random. Clamp delta time to 1/30. Resize handler. CODE HYGIENE: declare every table and constant at the top; no undefined vars, no TODO, no truncated functions; no console errors. Output one complete, working HTML file. Do not wrap the file in markdown. Start with <!DOCTYPE html>.
